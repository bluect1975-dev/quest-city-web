# Unit tests

Unit tests are co-located with their source (`packages/*/src/**/*.test.ts`, `apps/api/lib/**/*.test.ts`, `tools/*.test.mjs`) and run via each package's `test` script (`pnpm run test` at the root runs all of them). This directory is reserved for cross-package unit-level tests if a genuine need arises later; none exist at WEB-M0.
